Guessing Bot · Among Us

Guess modded roles from descriptions.

Guess The Role is a Game Bot for Modded Among Us communities. Start rounds, guess role names, use hints, and compete on leaderboards.

Add to Discord Support

What it supports

  • Role pools: Endless Host Roles (EHR), Town of Host Optimized (TOHO)
  • Leaderboards and user stats
  • MongoDB persistence for scores and server settings

How It Works

Fast to learn, hard to master.

Gameplay stays simple while role knowledge depth keeps rounds competitive.

1) Start a round

Use /start. The bot posts a role description without the role name.

2) Guess the role

Use /guess <role> or the Guess button under the round message.

3) Climb rankings

Earn points for correct guesses and track your progress in leaderboards.

Commands

Core command set

Slash and prefix commands are both supported for most gameplay actions.

/start

Start a new round in the configured game channel.

/guess <role>

Submit a role guess for the current round.

/hint

Reveal the next hint (up to 3 hints per round).

/leaderboard

Show server leaderboard (use scope:global for global).

/mystats

View your score, rank, correct guesses, and wrong guesses.

/gamehelp

Interactive help menu for users/admins.

/end

Ends the current round.

/settings

Admin panel to set game channel and enabled role pools.
